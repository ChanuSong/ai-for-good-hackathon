# MVP 요구사항·사용자 경험

기준일: 2026-09-17 · 준비 점검 방향으로 재설정

## 1. 이번 검증의 범위

**서초구 난임 지원을 준비하는 외국인 여성·한국인 남성 법률혼 합성 가구**를 유지한다. 지역은 데모 자료 범위이며 실제 사용자 거주지나 의료 상태가 아니다. [범위·근거](08-source-register.md)

목표: 낯선 서류를 이해하고 미확인 조건·준비 누락을 찾아, 다음 행동과 질문을 정리하는 데 추가 가치가 있는지 검증한다.

현재 산출물은 [로컬 비교 프로토타입](../prototype/README.md)이다. 생성형 AI·실제 신청·배포·실사용자 효과 검증은 아직 없다. 고정 자료·규칙 기반으로 A/B 구성 차이를 비교한다.

## 2. 화면과 흐름

합성 조건 선택 → 쉬운 용어 설명 → 직접 제출·공무원 조회·본인정보 제공 요구 구분 → 필요한 공식 준비 경로 → 남은 확인·근거 → 문의 준비서.

| 화면 요소 | 현재 기능 |
| --- | --- |
| 조건 선택 | 지역·혼인·보험 확인·시술 시작 여부·목록 확인 자기보고 |
| A 정적 안내 | 같은 claim·출처·질문을 연속 안내 |
| B 준비 점검 | 같은 내용을 미확인 조건·문의 질문·근거로 묶음 |
| 용어 도움 | 가족관계증명서·행정정보 공동이용의 쉬운 설명; A/B 공통 |
| 서류 준비 | 정부24 구분 3종·공식 준비 경로 3개. 전부 필수·전부 면제로 확정하지 않음 |
| 문의 준비서 | 합성 조건·질문·공식 출처·검토 전 표시, 복사·인쇄 |
| 언어 | 한국어·일본어, 상태 유지; 번역 사람 검토 전 |

## 4. 이번 검증에서 제외

- 이사·전세대출 절차. 전세대출 경험은 문제 조사 자료로만 사용한다.
- 가족 역할 배정·Task 완료·가족 동시 접속.
- 최종 자격·준비 완료 판정, 자동 기한 계산.
- 실제 문서 업로드·등록번호·건강 기록·서류 발급·정부 사이트 제출.
- 무료 상담이나 기존 포털이 열등하다는 전제.

이전 FR-01~11과 Task 흐름은 초기 로드맵 설계 이력이다. 현재의 구현·검증 우선순위는 PR-01~11이며, 기존 Task 데이터는 근거 재사용·후속 확장 참고로 남긴다.

## 5. AI 추가 조건

정보 구성의 가치가 확인되면 AI로 다양한 표현의 사건·조건을 추출하거나, 등록 용어를 설명하는 실험을 한다. 새 요건·기한·기관·검증 상태를 생성하지 못하도록 경계를 유지한다. 같은 자료의 정적·규칙 방식보다 나아진 점이 없으면 AI를 핵심 경쟁력으로 내세우지 않는다.

## 6. 후속 요구사항 후보 — 아직 미구현

H01이 선택한 병목은 필요 서류 판단, 발급 사이트·메뉴 탐색, 로그인·인증·발급 옵션 단계다. 다음 개선 단위는 여러 사업 확장이 아니라 **서류 하나의 준비 경로**다.

- 필요성: 어떤 조건에서 필요하고 조회로 대체 가능한지 근거와 미확인 항목을 구분한다.
- 경로: 공식 페이지와 실제 메뉴 이름을 연결한다. 로그인 이후 확인하지 않은 단계는 추측하지 않는다.
- 선택 안내: 누가 신청하는지, 인증 수단, 발급 옵션에서 무엇을 확인해야 하는지 설명한다. 인증·권한 제한 자체를 설명만으로 해결했다고 하지 않는다.
- 검증: 사용자가 다음 행동·확인할 선택지를 설명하는지, 여전히 기관 확인이 필요한 부분을 구분하는지 관찰한다.

현재 PR-01~11 완료 주장과 구분한다. 개인별 옵션값·신청 권한·인증 가능성은 아직 확정되지 않았다.

## 7. 약제비 청구와 현재 앱의 차이

후속 경험은 시술 전 지원 신청뿐 아니라 시술 후 약제비 청구·잔액 확인·방문 미해결을 포함한다. 현재의 시술 전 범위 밖이다. [13 분석](13-discovery-to-application.md)은 다음 검증 설계이며 구현 완료 명세가 아니다. 타 지역 안내를 서초구 사례에 섞거나 미확인 잔액을 0원으로 표시하지 않는다.

## 8. 상황 중심 목표 흐름 — 현재 앱과 구분

외부 포스트가 없어도 시작할 수 있어야 한다. 최소 상황 입력 → 관련 사업·업무와 해당 이유·추가 확인 → 지금 할 행동 선택 → 쉬운 단계 실행 → 막힘 해결·처리 확인을 목표로 한다. 최초에는 데이터 연계 없이 직접 입력으로 검증 가능하다.

첫 대상은 디지털 조작이 가능하나 한국 행정의 조건·용어·순서에서 막히는 사람이다. 안내만으로 수행이 어려운 사용자를 위한 가족 공동 사용은 후속 범위다. 본인 인증·서명·대리 가능 여부는 실제 업무의 권한을 따른다. 현재 앱에 상황별 사업 추천·가족 협력·기관 연계를 이미 구현한 것으로 표시하지 않는다.
