# 첫 데모 범위·공식 근거 등록부

기준일: 2026-09-17 · 공개 원문 열람: Codex · 사람에 의한 행정정보·일본어 검토 및 담당기관 확인: 미실시

## 1. 선정한 범위

**서초구에서 안내하는 난임부부 시술비 지원의 신청 준비부터 지원결정통지서 확인·의료기관 제출 준비까지**를 첫 데모로 한다. 사용자가 특정 지역을 지정하지 않고 선정에 맡겼으므로, 혼합국적 부부 관련 설명과 문의 창구가 공개된 서초구를 작업 기준으로 선택했다. 팀 전체의 최종 합의나 서초구와의 협약을 뜻하지 않는다.

- 합성 가구: 일본 국적 여성과 한국 국적 남성, 법률혼, 한국인 배우자의 주민등록 주소지는 서초구.
- 합성 조건: 시술 시작 전, 최초 신청 준비. 보험 등 조건은 `예 / 아니오 / 모름`으로 확인한다.
- 일본 국적은 언어·페르소나 설정이다. 일본인만 지원되는 사업이라는 뜻이 아니다.
- 범위 밖: 사실혼 세부 절차, 다른 지역, 양쪽 모두 외국인인 사례의 판단, 시술 시작 후 소급 여부, 지급액·잔여 횟수 계산, 치료 선택, 실제 신청·지급 처리.
- 범위 밖이라는 이유로 실제 사업의 지원 불가를 선언하지 않는다. 이 데모가 안내할 수 있는 범위의 한계로 설명한다.
- 현재 산출물은 **공식 원문을 대조한 데모 준비 자료**다. 기관 검증·개인별 자격 승인·사용자 검증을 완료한 서비스가 아니다.

`source_checked`는 Codex가 공개 원문과 기록을 대조했다는 뜻이다. `verified`는 사람이 해당 주장·적용 범위·표현을 검토한 뒤에만 사용할 수 있다. 충돌 해결에는 담당기관 답변의 날짜·조건·검토자를 추가한다. 출처가 공식이라는 이유만으로 전체 로드맵을 `verified`로 바꾸지 않는다.

## 4. 확인이 필요한 실제 항목

### X-01. 유효기간 상충

서초구 안내의 통지서 유효기간과 서울시 종합 안내의 기간이 다르다. 어느 문서가 개정 전인지 확인되지 않았다. `C-06`의 양쪽 값을 함께 보여주고 `deadline = null`을 유지한다. 더 길거나 짧은 값을 임의로 채택하지 않는다.

### X-02. 체류 증빙 적용 범위

서초구는 사실혼 추가서류 항목에 체류 증빙을 배치하고, 서울시 종합 안내는 외국인 추가서류로 서술한다. 사실혼 문단의 요구를 법률혼 데모에 자동 적용하거나, 법률혼에는 필요 없다고 단정하지 않는다.

### X-03. 온라인 신청과 배우자 대리

외국인 당사자의 인증 수단, 이용 가능한 신청 경로, 배우자가 대신 신청할 때 필요한 권한·서류는 직접 확인하지 못했다. 앱의 담당자 선택은 준비 업무의 분담이다.

## 5. 기관 확인 질문 초안 — 아직 연락하지 않음

문의 창구는 C-03에 연결한다. 실제 연락은 팀 담당자가 맡는다.

1. 외국인 여성·한국인 남성의 법률혼 가구가 첫 신청을 준비할 때, C-04 외에 체류·혼인 관련 추가 확인이 필요한가?
2. 두 안내의 C-06 차이 중 현재 해당 신청에 적용할 기준과 공식 근거는 무엇인가?
3. 해당 가구에서 외국인 당사자가 사용할 수 있는 온라인 경로·인증 방법은 무엇인가? 방문 또는 대리 신청은 어떻게 확인해야 하는가?

기록 양식: `질문 ID / 문의일 / 창구·담당 부서 / 적용 조건 / 답변 요약 / 추가 공식 문서 / 기록자 / 반영한 주장 ID`. 기관 담당자의 불필요한 개인정보는 기록하지 않는다.

## 6. 갱신과 공개 기준

- 행사 당일 시연 전에 데이터 담당자가 두 원문과 충돌 항목을 재확인한다.
- 사람이 원문과 한일 표현을 검토하기 전에는 화면에 ‘공식 원문 대조 · 팀 검토 전’을 표시한다.
- 해결되지 않은 충돌을 보여주는 데모는 가능하지만, 해결된 정확한 기한이나 자격 판정으로 소개하지 않는다.
- 후속 실증은 담당기관 확인, 검토자 지정, 참여자 동의·데이터 처리 범위 확정 후 시작한다.
- 시범 운영 제안: 주 1회 및 변경 통보 시 확인. 담당자가 배정되지 않으면 실제 이용자를 받는 운영으로 전환하지 않는다.
