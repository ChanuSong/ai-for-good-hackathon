# SeoulMate 발표용 공공성·통계 근거

확인일: 2026-09-17. 목적은 6인 팀이 공유할 공공적 문제와 검증 계획을 뒷받침하는 것이다. 개인·가족 경험은 내부 발견 자료로 유지하고 발표의 주인공으로 사용하지 않는다.

## 공공적 목적과 논리

**언어와 행정 경험의 차이 때문에, 자격이 있는 주민이 필요한 공공서비스를 이용하는 데 불필요한 장벽을 겪지 않는 사회를 만든다.**

인구 구성의 변화 → 행정 접근성의 중요성 → 일상적인 디지털 이용과 특정 행정 수행의 구분 → 공식 절차에서 확인되는 분기 → 실행 지원 설계 → 실제 접수·가구 부담으로 평가한다.

인구 증가만으로 신청 실패를 입증할 수 없다. 디지털 서비스 이용률도 신청 실패율을 뜻하지 않는다. 공식 안내의 복잡성과 내부 경험은 문제의 작동 방식을 보여주지만, 전체 이주민의 발생 빈도와 SeoulMate의 효과는 추가 검증이 필요하다. ‘앞으로 필연적으로 증가’라는 무조건적 예측 대신 관측된 인구 변화와 이미 진행 중인 정책 대응을 사용한다.

## 절차의 복잡성을 입증하는 공식 사례

- [동대문구 난임부부 시술비 지원](https://www.ddm.go.kr/health/contents.do?key=1274): 약제비에 5개 서류 항목, 시술 종료 시 병원 원무과에서 잔액 확인 후 보건소 방문 신청 안내. 병원·약국·보건소는 자료·처리에 관계되는 3개 기관 유형이며 반드시 각각 방문해야 한다는 뜻은 아니다.
- [금천구 난임부부 시술비 지원](https://www.geumcheon.go.kr/health/contents.do?key=1487), 수정 2026-02-26: 시술비는 병원이 청구하고 약제비는 개인이 청구. 약제비는 방문·이메일·e보건소 경로를 제시하되 e보건소는 해당 경로로 시술비 지원을 신청한 사람만 가능하다는 조건이 있음.

이는 적용 조건·서류·기관·접수 경로가 연결된 문제임을 보여준다. 두 자치구 정보를 하나의 개인에게 적용되는 절차로 합치지 않는다. 사용자 실제 관할이나 현재 서초구 데모의 약제비 규칙으로 사용하지 않는다. 전국 평균 부담·누락 규모·지원금 손실은 이 자료로 산정할 수 없다.

## 국내 정책과 해외에서 가져올 운영 원칙

[서울시 MY SEOUL+ 개편, 2026-09-01](https://www.seoul.go.kr/news/news_report.do?nttNo=465100)은 유형별 맞춤정보·다국어·AI 챗봇·상담 예약·일부 프로그램 신청을 제공한다. 기존 정책의 문제 인식과 기반을 보여준다. 상황별 추천·번역·질문 생성만으로 SeoulMate의 차별성을 주장하지 않는다. SeoulMate가 검증할 차이는 특정 업무의 정확한 실행·막힘 대응·처리 확인이다. 연동·협약·우위는 현재 미확인이다.

[호주 Multicultural Service Officers](https://www.servicesaustralia.gov.au/what-multicultural-service-officers-do?context=22066)는 복잡한 사례 지원과 기관 간 협력을 수행한다. [캐나다 Service Canada COLS](https://www.canada.ca/en/employment-social-development/services/community-outreach-liaison-service.html)는 신청 지원 행사와 지역기관을 통한 담당자 직접 연결을 제공한다. 참고할 원칙은 다국어 안내에 실행 도움과 사람의 책임 있는 연결을 더하는 것이다. 해외 제도의 존재만으로 효과·한국 대비 우위를 확정하지 않는다. 상세 비교는 [기존 조사](14-australia-canada-lessons.md)에 있다.

## 효과를 수치화하는 방법

현재 SeoulMate의 접수 완료율·절감 시간·수급 증가액은 측정 전이다. 배경 통계와 제품 효과를 같은 종류의 수치로 제시하지 않는다.

- 접수 확인: 실제 접수된 건수 / 실제 신청을 시도한 적격 사례 수. 관찰 기간 내 진행 중인 사례·적격 여부 미확정 사례는 별도 집계한다.
- 가구 활동 시간: 신청자 + 가족의 검색·준비·조작·방문 활동 시간을 합산한다. 단순한 가족 간 부담 이전을 절감으로 처리하지 않는다. 대기기간은 별도 기록한다.
- 정확성·기관 수고: 중대한 오안내, 보완 요청, 재방문, 담당자 대응 시간 및 자료 갱신·지원 운영 비용을 기록한다.
- 확대 효과 산식: 관측된 건당 절감 시간 × 실제 도움을 제공한 업무 건수. 규모 가정과 관측값을 구분한다.

계산 예시로 ‘연 1,000건 × 건당 30분 = 연 500시간’을 사용할 수 있지만 두 입력값은 모두 임의 가정이며 예상·목표·성과가 아니다. 발표 본문에는 검증 전 임의 숫자 대신 지표와 분모를 넣는다. 추가 수급 효과를 원래도 받을 지원금 전액으로 계산하지 않는다.

## 남은 핵심 근거

‘디지털 이용이 가능하지만 행정 실행에서 막히는 사람’이 해당 사업에 얼마나 많은지, 구체적 원인 중 안내로 해결 가능한 비중이 얼마인지, 기존 서비스보다 SeoulMate가 얼마나 개선하는지는 아직 모른다. 최신 전국다문화가족실태조사 결과의 관련 항목은 이번 작업에서 직접 검증하지 못해 발표 수치로 사용하지 않았다.

이 공백은 개인 감성이나 인구 수로 메우지 않는다. 첫 업무의 실제 경로 확인, 기존 안내와 비교 과제, 실제 접수 추적을 다음 검증으로 명시한다.
