# 사용자·가치 검증 계획

기준일: 2026-09-17 · 직접 경험 응답자 1명, 본인 가구·부모님 업무 경험; 화면 사용성 테스트 미실시

## 1. 현재 근거 수준

남편 응답자가 난임 지원·전세대출 준비를 맡았고, 배우자의 행정 용어·경험 부족을 이유로 설명했다. 이는 남편의 직접 업무 경험과 배우자에 대한 남편의 해석이다. 아내 본인의 답변·참여 의향·불만으로 바꾸지 않는다. [내부 기록 H01](research/session-H01.md)

공식 출처 대조, MY SEOUL+ 관찰, 자동 테스트, 실제 사용자 효과를 각각 기록한다. 결과는 [실행 기록](12-comparative-validation.md)에서 확인한다.

## 2. 먼저 물을 실제 경험

1. 기억나는 서류 한 가지는 무엇인가? 정확한 이름이 아니어도 된다.
2. 필요한 것을 어디에서 알았고, 어떤 순서로 준비했는가?
3. 어려웠던 지점은 용어 이해·필요 항목 판단·발급 경로·인증·권한·시간 중 무엇이었는가?
4. 당시 도움으로 충분했던 것은 무엇이고, 무엇이 남았는가?
5. 지금 분담을 바꾸고 싶은가, 그대로 두되 설명·검색 부담만 줄이고 싶은가?

인증·권한 문제를 이해 부족으로 바꾸지 않는다. 아내가 직접 할 수 있을 것 같다는 남편의 예상은 실제 당사자 수행 결과와 구분한다. 의료·계좌·식별번호는 묻지 않는다.

## 3. 10~15분 비교 세션

| 순서 | 시간 | 진행 |
| --- | --- | --- |
| 안내 | 1분 | 자발적 참여·중단 가능·합성 사례·기록 범위 설명 |
| 최근 사례 | 3분 | 한 서류의 실제 준비 과정·막힌 지점 회상 |
| 용어 확인 | 2분 | 낯선 용어를 설명해 보게 한 뒤 쉬운 풀이가 도움이 되는지 확인 |
| A/B 과제 | 6분 | 각 3분, 같은 정보·언어·용어 도움 설정으로 다음 행동·미확인 항목·질문 찾기 |
| 사후 | 2분 | 어느 수고가 줄거나 늘었는지, 필요 없는 기능은 무엇인지 질문 |

행사 30분 슬롯에는 1명 전체 세션을 먼저 배치한다. 2명 진행은 10분씩 축소하거나 복수 진행자를 둔다. 기존 1~2명×8분 계획은 역할 조작 점검이었으며 이번 비교 과제 계획으로 대체한다.

## 4. 실험 조건

[로컬 실행](../prototype/README.md) 후 A부터 또는 `?view=B`로 시작한다. 두 명이면 순서를 번갈아 적용한다. 같은 사람이 같은 내용을 두 번 보기 때문에 학습 효과가 생긴다. 순서·도움·이전 행정 경험을 기록하고 인과 효과나 통계적 우위로 발표하지 않는다.

- 용어 실험과 화면 구성 실험을 구분한다. 쉬운 풀이만으로 문제가 풀리면 복잡한 구성의 추가 가치를 아직 입증하지 못한 것이다.
- A/B 구성 비교에서는 용어 도움을 양쪽 동일하게 설정한다.
- 정적 안내 A는 같은 기준 자료로 만든 비교 화면이다. MY SEOUL+의 실제 답변과 동일하다고 설명하지 않는다.
- 가족 역할 버튼을 누르는 과제는 삭제한다.

## 5. 과제와 사전 채점

| 과제 | 독립 성공 기준 |
| --- | --- |
| 서류·용어 이해 | 용어의 뜻과 다음 준비 행동을 자기 말로 연결. 모든 서류 생략 같은 과잉 일반화 없음 |
| 직접 발급 필요성·경로 | 목록 전체를 필수로 보지 않음. 동의·조회 조건과 실제 적용을 구분하고 필요한 경우 공식 준비 경로를 찾음 |
| 미확인 조건 찾기 | 합성 프로필의 보험 미확인과 자료 자체의 충돌·적용 불명확을 구분 |
| 근거와 다음 행동 | 관련 공식 출처와 담당 창구 또는 확인할 행동을 찾음 |
| 문의 질문 구성 | ‘무엇을, 내 어떤 조건에서 확인할지’를 구체적으로 말함. 확정되지 않은 기한·자격을 단정하지 않음 |

각 과제는 `독립 성공 / 도움 후 성공 / 실패 / 미실시`로 기록한다. 시간은 회상한 과거 소요 시간과 직접 비교하지 않는다. ‘문의 필요’ 문구를 읽은 것만으로 질문 작성 성공을 인정하지 않는다.

## 6. 유지·수정·전환 기준

- **유지:** 실제 준비 부담이 구체적이고, B에서 A 때 놓친 중요 항목을 찾거나 질문을 더 정확히 구성하며 새로운 오해가 없음.
- **단순화:** 쉬운 용어 풀이·정적 안내만으로 충분하거나 B의 입력·상태 관리가 부담.
- **사례 전환:** 난임 사례 필요성을 확인하지 못하고 다른 접근 가능한 사건에서 반복 부담이 나타남.
- **접근 전환:** 인증·법적 권한·기관 처리 문제가 핵심으로, 설명·질문 개선으로 달라지지 않음.

2명 이하에서는 탐색적 방향 결정만 한다. 긍정 평가 한 마디나 화면 선호를 시장 검증으로 삼지 않는다. 한 명이라도 자격 승인·확정 기한으로 오해하면 해당 표현부터 수정한다.

## 7. 지표

핵심: 누락·오해 없는 준비 행동/질문 구성, 과제별 성공·도움, 추가 입력 부담. 후속: 가구 전체 활동 시간, 반복 설명, 준비 누락·재방문 원인. 기관 대기시간은 분리한다.

기존 Administrative Participation Rate는 보조 지표로 내린다. 사용자가 원하는 참여 수준과 기존 분담 만족도를 함께 확인하며 배우자 단독 수행을 무조건 실패로 보지 않는다. 실제 수행을 측정하지 않으면 참여율은 보고하지 않는다.

## 8. 기록·공개

[세션 템플릿](templates/validation-session.md)을 사용한다. 남편 대리 설명·당사자 직접 답변·진행자 해석을 구분하고 표본은 가구 단위도 기록한다. 현재 화면 사용자 테스트 결과는 없다.

대화에서 자발적으로 제공한 경험은 내부 검증 기록으로 정리한다. 외부 발표·인용 동의는 별도로 확인한다. 원메모 삭제 기본일은 행사 후 7일인 2026-09-25, 접근은 팀의 지정 담당자로 제한한다.

## 통합 서비스 기준 적용

현재 A/B 도구는 시술 전 안내 배열 비교다. 새 약제비 흐름의 검증을 대신하지 않는다. 첫 실행 검증의 단계·가구 시간 합산·실제 접수 확인·운영 비용·후속 실증 규모는 [15 서비스 정의](15-service-definition.md)를 따른다. 정량 예시는 계산법이며 성과·예측값이 아니다.
