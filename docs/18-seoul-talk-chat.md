# 서울톡 기반 지식의 다국어 채팅 — 목업

작성·자료 확인: 2026-09-18

## 방향

서울시가 서울톡의 기반 지식 또는 재사용 가능한 답변 자료를 제공한다는 가정 아래, SeoulMate에서 사용자가 선택한 언어 또는 질문 언어로 안내한다. 서울톡 카카오톡 대화창을 자동 조작하거나 답변을 수집하는 방식은 사용하지 않는다.

서울톡은 서울시 행정정보 안내·공공서비스 예약·민원 등을 제공하는 기존 채널이다. SeoulMate의 제안은 제공받은 지식의 다국어 접근성과 실제 준비 절차로의 연결이다. MY SEOUL+도 다국어 챗봇을 제공하므로 “다국어 채팅 자체가 서울시에 없다”는 차별화 주장은 하지 않는다.

사용자가 지적한 서울톡 한국어 이용 경험은 문제 가설로 기록한다. 현재 공개 안내만으로 전체 서비스의 지원 언어, 외부 API 제공 여부 또는 데이터 재사용 권한을 확정하지 않는다. 운영기관 확인이 필요하다.

## 지금 동작하는 목업

- 하단 `채팅` 탭: 질문 입력, 답변 대기 표시, 대화 기록, 새 대화.
- 답변 언어: 질문 언어 자동 선택 또는 한국어·일본어·영어 지정. 지정 언어가 우선한다. 화면 언어는 기존 한국어·일본어를 유지한다.
- 질문 언어 자동 선택은 문자 기반 규칙이다. 모든 언어·혼합 문장의 판별을 보장하지 않으며, 지원 언어로 판별하지 못하면 화면 언어를 사용한다.
- 공개 공식 안내를 바탕으로 작성한 고정 답변: 금천구 난임 약제비, 필요 서류·잔액 확인 창구, 서울시 공공시설 예약, MY SEOUL+ 통역·상담 지원.
- 앞선 약제비 대화가 있을 때 짧은 서류·잔액 후속 질문을 이어받는다. 범위 밖 질문에는 답을 생성하지 않는다.
- 답변별 공식 출처·확인일, 펼쳐 보는 한국어 답변, 준비 절차 또는 기관 링크.
- 준비 절차 버튼은 금천구 예시 업무로 이동하며 기존 준비 진행 상태를 유지한다. 영어 채팅에서 이동한 준비 화면은 기존 화면 언어를 따른다.
- 입력·기록은 메모리에만 유지되며 새로고침하면 사라진다. 질문은 외부로 보내지 않는다.

서울톡 DB를 실제 제공받지 않았다. 예시 자료가 서울톡에 실제 수록되어 있다는 주장도 하지 않는다. DB/API/생성형 AI/실시간 번역/잔액 조회/예약·신청 대행은 미연결이다. 화면의 `서울톡 지식 연계 · 데모`를 누르면 이 범위를 확인할 수 있다. 한국어 답변 펼침은 작성한 기준 답변이며 원문 인용이 아니다.

## 서울시에 요청할 것

선정 업무의 지식 항목·기준 답변·공식 원문 URL·담당 기관·관할·적용 조건·시행일·갱신일·버전·폐기 상태를 포함한 시범 자료 제공과 번역·재사용 허용 범위를 요청한다. 이용자 개인 상담 기록은 요청 대상에 포함하지 않는다.

첫 연계는 기관이 제공하는 파일 또는 허용된 조회 인터페이스로 구성할 수 있다. 실제 협의 후 방식과 권한을 결정한다. 자료 변경·폐기 통지와 담당자 검수 절차도 필요하다.

실서비스에서는 원문 검색 결과에 근거해 답변하고, 자격·기한·금액·관할을 임의로 변경하지 않아야 한다. 언어별 의미 일치, 근거 없는 답변 비율, 준비 단계 진행·상담 재설명 감소를 검증한다. 현재 목업의 규칙 분류·고정 번역은 그 성능 검증 결과가 아니다.

## 시연

1. 채팅 → `薬代の助成はどう申請しますか？` → 일본어 답변·공식 출처.
2. 한국어 답변 펼치기 → 안내 내용 비교.
3. 답변 언어를 `English`로 지정 → `필요한 서류는?` → 영어 후속 답변.
4. 답변의 준비 절차 버튼 → 기존 금천구 실행 안내.
5. 새 대화 → 공공시설 예약 또는 통역 지원 → 공식 서비스 링크.
