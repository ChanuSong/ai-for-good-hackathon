# MY SEOUL+ 연계 제안과 목업 구현

기준일: 2026-09-18. 공식 제휴·API 연동이 아니라 기존 공공서비스를 보완하는 시범 연계 제안이다.

## 판단

MY SEOUL+는 2026-09-01 서울외국인포털을 개편해 출시했다. 행사 17일 전의 정책 방향과 맞닿아 있어 실현 가능성·정책 연결성을 설명하기 좋은 맥락이다. 최근 출시됐다는 사실 자체가 제품 효과나 심사 가점을 보장하지 않는다.

**발표 제안: MY SEOUL+에서 찾은 정책을 MARO의 실행 안내로 이어주고, 막힌 단계는 기존 상담·지원기관과 연결한다.**

서울시는 유형별 맞춤정보, 다국어, AI 챗봇, 상담 예약 및 일부 프로그램 신청을 이미 제공한다. 단순 추천·번역·링크 추가만으로 차별성을 주장하지 않는다. 특정 업무에서 준비 누락·막힘·반복 설명을 줄이는지는 별도 검증한다.

## 연계 수준

| 단계 | 연계 | 현재 상태 | 필요한 협력 |
| --- | --- | --- | --- |
| 공개 링크 | MARO의 도움 화면 → MY SEOUL+ 가족상담·통번역 안내 | 목업에 구현. 한국어 문의 문구를 복사할 수 있고 일본어 화면에도 한국어 질문을 함께 제공 | 외부 페이지 이용 조건·지원 언어·상담 범위는 해당 기관에서 확인 |
| 진입 연결 | MY SEOUL+의 선정 정책 페이지/챗봇 → 해당 업무의 MARO 실행 화면 | 제안. 포털 변경·실제 유입 연동 없음 | 운영부서 승인, 사업·콘텐츠 식별자와 업무의 대응표, 한 사업 진입 버튼 |
| 상담 연결 | 사용자가 확인한 조건·막힌 단계·질문을 정리해 상담자가 참고 | 현재는 사용자 복사. 자동 전송·접수 없음 | 동의·최소 항목·담당자 수신·회신 절차 협의 |
| 변경 관리 | 정책 개정 시 실행 안내의 근거·버전 갱신 | 공식 페이지 수동 확인. 자동 수신 없음 | 변경 통보 담당·주기·책임, 제공 가능한 데이터 인터페이스 확인 |
| 처리 확인 | 접수·보완·지급 결과를 기관 정보와 연결 | 미구현 | 해당 업무 소관 기관의 권한·동의·상태 제공 범위 협의 |

API 공개 여부, SSO, 사용자 프로필 공유 가능성은 확인하지 않았다. 구현 가능한 것으로 가정하지 않는다. 초기 공개 링크와 사용자 복사는 별도의 API 없이 동작한다.

## 목업에서의 역할 구분

약제비 잔액·청구 조건·접수 여부: 금천아이맘건강센터 문의.

통역·가족센터 지원 탐색: MY SEOUL+의 가족상담 및 통·번역 안내로 이동. 이 페이지는 약제비 자격 판정·실시간 통역 배정·신청 접수 창구가 아니다. 일본어 지원이나 즉시 상담을 보장하지 않는다.

이동 시 입력 내용·진행 상태·의료정보를 URL에 붙이지 않는다. 외부 페이지는 새 탭으로 열고 사용자가 직접 다음 행동을 선택한다. MY SEOUL+의 로고·공식 제휴 배지를 사용하지 않는다.

## 심사에서의 설명

- 정책 연결: 서울시의 새 포털이 지향하는 정착·생활 지원을 선정 업무의 실행까지 확장하는 제안.
- 실현 가능성: 새 통합 행정 시스템 전체 구축에 앞서, 한 업무의 링크·절차·담당 연결로 실증 가능.
- 작동성: 시연에서 ‘도움 요청 → 한국어 질문 복사 → MY SEOUL+ 지원 안내’를 직접 보여줄 수 있음. 기관 전송·접수 연동 시연은 아님.
- 차별성: 단순 링크는 차별성이 약하다. 기존 안내만 이용할 때와 비교해 다음 행동 정확도·반복 설명·준비 및 접수 부담의 개선을 보여줘야 함.

서울시에 요청할 첫 협력은 ‘MY SEOUL+ 운영부서 + 선정 사업 담당자 + 지원센터’의 한 업무 공동 검토와 시범 진입 경로다. 개인정보·의료정보 공유는 초기 실증의 선행 조건이 아니다.

## 검증 지표

포털 안내에서 MARO로 넘어온 실제 유입이 생기면 안내 시작·이탈 단계·실제 다음 행동을 관찰한다. 상담 연결은 버튼 클릭, 예약 신청, 상담 수행, 문제 해결을 구분한다. 단순 외부 링크 클릭을 상담 완료로 집계하지 않는다. 실제 접수와 가구 시간, 공공 담당·자료 갱신 비용을 함께 측정한다.
