# SeoulMate 서비스 정의와 검증 기준

기준일: 2026-09-18 · 제품 방향 고정, 효과·사업성 검증 전

## 공공적 목적

언어와 행정 경험의 차이 때문에 자격이 있는 주민이 필요한 공공서비스를 이용하는 데 불필요한 장벽을 겪지 않는 사회를 지향한다.

SeoulMate는 외국인 주민을 번역이 필요한 사람으로만 보지 않는다. 디지털 도구와 일상 한국어를 사용할 수 있어도 낯선 제도에서는 어떤 업무가 필요한지 판단하고, 기관별 절차를 연결해 실제 처리를 확인하는 데 추가 비용이 생길 수 있다.

## 1. 제품 정의

SeoulMate — My Administrative Roadmap은 내 상황에서 필요한 지원사업·생활행정을 찾고, 지금 할 행동부터 막힘 해결과 처리 확인까지 이어주는 행정 실행 코파일럿이다.

핵심 루프:

Discover → Plan → Act → Unblock → Confirm

- Discover: 공식 사업명을 몰라도 자신의 상황에서 시작한다.
- Plan: 검토된 범위 안에서 필요한 업무와 미확인 조건을 정리한다.
- Act: 한 번에 한 행동을 실행 가능한 순서로 제시한다.
- Unblock: 실패·불확실성에 맞는 질문과 사람·기관 연결을 준비한다.
- Confirm: 사용자의 준비·제출 자기보고와 기관의 실제 접수·보완·지급 상태를 구분한다.

첫 대상은 디지털 도구 사용이 가능하지만 한국 행정의 조건·용어·순서에 익숙하지 않은 사람이다. 혼합국적 가구의 외국인 배우자를 첫 발견 사례로 삼지만, 가족이 합의해 한 사람이 처리하는 것 자체를 실패로 보지 않는다.

## 2. 풀 문제와 현재 근거

문제: 자신의 상황에 맞는 지원과 필요한 업무를 판단하고 여러 기관의 절차를 연결해 신청·청구까지 마치는 데 과도한 수고가 들거나 중간에 진행이 멈출 수 있다. 가족 중 제도에 익숙한 사람이 검색·판단·준비를 집중적으로 맡을 수 있다.

확인된 근거:

- 한 가구의 난임·전세대출 경험에서 필요 서류 판단, 여러 발급 경로 탐색, 로그인·인증·옵션 단계의 부담이 보고됐다.
- 공식 난임 안내에서도 자격·잔액·서류·접수 경로가 하나의 사용자 업무 안에서 연결된다.
- MY SEOUL+ 등 국내 서비스는 다국어·맞춤정보·챗봇·상담 접근을 이미 제공한다.
- 호주·캐나다는 통역뿐 아니라 복잡한 사례 지원·신청 지원·사람 연결을 운영한다.

아직 확인되지 않은 것:

- 이 문제가 전체 외국인 주민에게 얼마나 자주 발생하는지
- SeoulMate가 기존 안내·상담보다 실제 접수·시간·보완을 얼마나 개선하는지
- 기관의 도입·구매 의사와 운영 비용

## 3. MVP와 현재 구현

장기 비전은 생활행정 전반이지만 첫 실행 검증은 난임 시술 후 원외 약제비 청구 한 건으로 좁힌다.

발표용 기본 데모는 다음을 구현한다.

상황 입력 → 5단계 실행 로드맵 → 지금 할 행동 → 단계별 공식 근거 → 막혔을 때 질문 → 사용자 준비 상태 확인.

현재 데모의 공식 근거는 금천구 보건소 안내이며, 개인별 잔액·자격·실제 접수 결과는 조회하거나 판정하지 않는다.

기존 서초구 시술 전 준비 A/B 도구는 연구용 화면으로 보존한다. 제품 데모와 검증 도구를 같은 화면으로 섞지 않는다.

생성형 AI는 아직 연결하지 않았다. AI를 연결할 때는 사용자 표현에서 사건·미확인 조건을 구조화하고 쉬운 설명을 만드는 역할에 한정한다. 행정 요건·기관·기한·URL은 검토된 데이터에서 조립한다.

## 4. 누구에게 어떤 수혜가 가는가

| 대상 | 기대 수혜 | 확인 방법 |
| --- | --- | --- |
| 직접 신청하는 사람 | 다음 행동 이해, 원하는 만큼 직접 수행, 미해결·누락 감소 | 실제 접수·도움 요청·오해·수행 단계 |
| 배우자·가족 | 대신 검색·설명·서류 준비하는 활동 시간 감소 가능 | 본인과 가족의 활동 시간을 합산 |
| 보건소·지원기관 | 반복 설명·보완 업무 감소 가능 | 보완·재방문·담당 시간 |
| 정부 | 적격 주민의 실제 접근과 실패 지점 파악 | 접수·미신청·탈락 원인과 분포 |

가족 간 역할 이전만으로 가구 전체 부담이 줄었다고 하지 않는다. 정책 접근이 좋아지면 신규 문의나 지원금 집행이 늘 수도 있으므로 정부 비용 절감을 확정하지 않는다.

## 5. 성공의 정의

초기 성공은 다음과 같다.

- 사용자가 중요한 누락 없이 지금 할 행동을 찾는다.
- 미확인 조건을 임의로 충족·불충족으로 바꾸지 않는다.
- 막혔을 때 누구에게 무엇을 물어야 하는지 안다.
- 사용자 체크와 기관 처리 결과를 구분한다.

후속 실증에서는 실제 접수 확인, 보완·재방문, 해결 기간, 본인+가족 활동 시간, 자료 갱신·상담 운영 비용을 측정한다.

## 6. 정부에 필요한 지원

초기에는 거대한 API보다 한 업무를 실제로 검증할 수 있는 책임 있는 연결이 먼저 필요하다.

1. 선정 사업 담당 창구가 적용 조건·서류·접수·보완·조회 경로를 검토한다.
2. 가족센터·외국인 지원기관과 자발적 참여자를 연결하고, 미해결 사례의 전달·회신 방식을 협의한다.
3. 효과가 확인되면 동의 기반 처리 상태 조회, 변경 통보, 허용된 가족 지원 권한 연계를 검토한다.

초기 프로토타입은 공개 자료로 검증할 수 있으며 신규 공공 시스템 구축을 선행 조건으로 두지 않는다.

## 7. 공공–민간 역할

공공은 공식 절차와 변경·예외에 대한 책임 있는 근거를 제공하고, SeoulMate는 상황 이해·실행 UX·다국어 설명·막힘 정리·오류 수정과 평가를 맡는다.

장기적으로는 다음 순환을 지향한다.

공식 행정정보 → AI 실행 지원 → 시민 사용 → 반복 장벽 발견 → 행정 개선

AI로 나쁜 행정을 감추지 않는다. 설명 부족은 제품이 돕고, 인증·권한·기관 시스템의 구조적 장벽은 별도의 행정 개선 과제로 구분한다.
