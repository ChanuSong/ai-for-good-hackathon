# MARO 서비스 정의와 검증 기준

기준일: 2026-09-17 · 제품 방향 고정, 효과·사업성 검증 전

## 공공적 목적

언어와 행정 경험의 차이 때문에 자격이 있는 주민이 필요한 공공서비스를 이용하는 데 불필요한 장벽을 겪지 않는 사회를 지향한다. 6인 팀의 발표는 이 목적과 공식 근거를 중심으로 구성한다. 개인·가족 경험은 내부 발견 자료이며 발표의 주인공으로 사용하지 않는다. 인구·디지털 이용 통계는 [발표 근거](16-public-interest-evidence.md), 구체적인 구성은 [9장 스토리보드](templates/pitch-script.md)를 따른다.

## 1. 판단

방향을 정할 만큼 문제와 사용 흐름은 구체화됐다. 이제 기능 범위를 더 넓히는 조사보다 한 업무의 실행과 비교 검증을 우선한다. 문제의 시장 규모·절감 효과·기관 구매 의사는 아직 알 수 없다.

**내 상황에서 관련 지원사업·행정업무를 찾고, 필요한 일을 쉬운 단계로 실행하도록 돕는다.** 막혔을 때 확인할 조건·이용 가능한 경로·도움을 연결하고 실제 처리 여부를 구분한다.

첫 대상은 디지털 도구 사용이 가능하지만 한국 행정의 조건·용어·순서에 익숙하지 않은 사람이다. 혼합국적 가구의 외국인 배우자를 첫 사례로 삼는다. 연령·국적만으로 수행 능력을 정하지 않는다. 지속적인 조작 도움이 필요한 사람의 가족 공동 사용은 후속 범위다.

## 2. 풀 문제와 근거

문제: 자신의 상황에 맞는 지원과 필요한 업무를 판단하고, 여러 기관의 절차를 연결해 신청·청구까지 마치는 데 과도한 수고가 들거나 중간에 진행이 멈춘다. 가족 중 익숙한 사람이 검색·판단·준비를 집중적으로 맡을 수 있다.

| 근거 | 확인된 것 | 아직 확인되지 않은 것 |
| --- | --- | --- |
| H01 경험 | 남편이 여러 서류를 발급·제출했고 필요 판단·사이트 탐색·인증/옵션에 수고가 있었다고 설명. 배우자의 약제비 방문 미해결·잔액 확인 어려움과 부모님 업무 지원 경험도 전달 | 배우자·부모님의 직접 수행 능력, 방문 미해결 원인, 빈도·시간, 전체 인구에서의 규모 |
| 공식 행정 안내 | 서류 제출·조회 구분, 약제비의 기관별 업무·경로 조건 등 실제 분기가 존재 | 사용자 개인에게 적용되는 잔액·권한·청구 조건 |
| 기존 국내외 서비스 | 맞춤 안내, 통역, 사례관리, 신청 지원 등이 공공 서비스로 제공됨 | MARO가 기존 안내·지원보다 낫다는 결과 |

문제 경험은 확보했지만 대표성 있는 수요조사나 제품 효과 검증은 아니다. 가족이 자발적으로 한 사람에게 일을 맡기는 것 자체를 문제로 취급하지 않는다.

## 3. 어떻게 풀 것인가

상황 입력 → 관련 사업·업무 후보와 이유 → 적용 확인·해야 할 순서 → 한 번에 한 행동 → 막힘 해결·지원 연결 → 처리 확인.

첫 검증은 **난임 시술 후 약제비 청구 한 건**에 집중한다. 공식 사업명을 몰라도 시작할 수 있어야 한다. 관할별 접수·인증·잔액 확인 경로의 근거 확보는 남아 있다. 사용자 실제 관할을 데모 지역으로 추정하지 않는다.

사용 흐름의 목표:

1. 시술 이후 약제비 청구를 준비하는 합성 상황에서 관련 업무를 찾는다.
2. 시술비 최초 신청과 약제비 청구를 구분하고, 잔액 등 미확인 사항을 먼저 찾는다.
3. 필요한 서류와 실제 이용 가능한 접수 경로를 확인한다.
4. 인증·옵션·방문에서 막히면 이유에 맞게 다음 확인·도움을 제시한다.
5. 제출 의사·클릭·자기보고와 기관의 접수·보완·지급 결과를 구분한다.

AI의 후보 역할은 사용자의 표현에서 상황·미확인 조건을 정리하고 검토된 절차를 쉬운 말로 설명하는 것이다. 공식 요건·기한·잔액·권한을 임의 생성하지 않는다. 실제 잔액·처리 상태 연계는 아직 없다. 첫 입력은 수동 선택으로도 검증할 수 있다.

현재 구현은 **서초구 시술 전 서류 준비 비교 도구**이며 위 약제비 흐름·상황별 사업 추천·기관 조회·AI 실행은 미구현이다. 기존 테스트 통과를 새 흐름의 완료로 간주하지 않는다.

## 4. 누구에게 어떤 수혜가 가는가

| 대상 | 기대 수혜 | 확인 방법 |
| --- | --- | --- |
| 직접 신청하는 사람 | 다음 행동 이해, 원하는 만큼 직접 수행, 미해결·누락 감소 | 과제 수행, 도움 요청, 실제 접수·보완 기록 |
| 배우자·가족 | 대신 검색·설명·서류 준비하는 활동 시간 감소 | 본인과 가족의 시간을 따로 기록한 후 합산 |
| 보건소·지원기관 | 조건·미해결 내용이 정리되어 반복 설명·보완 업무 감소 가능 | 담당자 처리 시간·보완 사유·연결 후 결과 |
| 정부 | 기존 정책의 실제 접근·이용 개선 가능 | 적격자의 접수·수급, 미신청·탈락 원인과 분포 |

정부의 비용 절감을 확정하지 않는다. 정책 접근이 좋아지면 신규 문의나 지원금 집행이 늘 수도 있다. 가족 간 시간 이전만으로 가구 전체 부담이 감소했다고 하지 않는다.

## 5. 얼마나 수혜가 가는가

**현재 정량 효과는 미측정이다.** 예상 수혜 인원·절감 시간·추가 수급액·예산 절감액을 성과처럼 제시하지 않는다.

핵심 지표:

- 비교 과제: 정확한 다음 행동과 독립 수행 단계, 필요한 도움, 오해·누락.
- 실제 이용: 접수 확인 비율, 보완·재방문 사유, 해결까지 걸린 기간.
- 가구 활동 시간: 본인과 가족의 검색·설명·조작·방문 준비 시간을 합산. 대기시간은 별도.
- 운영 비용: 자료 갱신·상담·기관 확인·AI/호스팅의 활동 시간과 비용.

가구 시간 절감 = 비교 가능한 기존 방식의 가구 활동 시간 − MARO 사용 시 가구 활동 시간. 예를 들어 같은 범위의 업무가 90분에서 60분으로 줄었다면 1건당 30분 절감이다. 이 숫자는 계산 예시이며 관측값·예상치·목표값이 아니다.

추가 수급 효과는 원래도 받았을 지원금 전액으로 계산하지 않는다. 실제로 놓칠 가능성이 있던 적격 청구가 완료됐는지와 지급 확인이 필요하다. 대조 없이 제품 기여를 확정하지 않는다.

검증 순서:

1. 해커톤: 1~2명의 합성 과제에서 다음 행동·오해·도움을 관찰. 시장·인과 효과를 주장하지 않는다.
2. 후속 탐색 실증: 한 사업·10가구 이내·4주를 협의안으로 삼아 실제 준비·접수·가구 시간을 관찰한다. 수급까지 기간이 부족하면 미관측으로 둔다.
3. 확대 판단: 같은 조건의 기존 안내·지원과 비교하고 자료·사람 지원 운영 비용까지 포함한다. 기존 안내로 충분하거나 시간 부담이 줄지 않으면 단순화한다.

## 6. 정부에 필요한 지원

| 단계 | 요청 | 목적 |
| --- | --- | --- |
| 프로토타입 | 공개 자료 활용; 신규 공공 시스템 구축은 선행 조건 아님 | 합성 사례로 초기 흐름 검증 |
| 첫 실증 | 선정 사업 담당 창구의 적용 조건·서류·인증·접수·보완·조회 경로 검토 | 추측을 줄이고 실제 가능한 행동을 제공 |
| 첫 실증 | 가족센터·외국인 지원기관의 자발적 이용자 연결과 미해결 사례 연결·회신 절차 협의 | 실제로 막힌 지점과 처리 결과 관찰 |
| 확장 | 실제 제공 가능한 범위의 동의 기반 상태 조회·대리 권한·변경 통보 연계 협의 | 재입력·조회·가족 지원 부담 감소 |

정부 지원을 ‘데이터와 예산을 달라’는 요청으로 끝내지 않는다. 한 업무를 실제로 처리할 수 있게 하는 검토 책임자·연결 절차를 먼저 요청한다. 현재 기관 협약·데이터 연계·실증 승인은 없다.

## 7. 지금 보완할 세 가지

1. **실행 경로:** 약제비 한 건의 관할별 접수·인증·잔액 확인·실패 후 경로를 확보한다. 해결할 수 없는 지점도 명시한다.
2. **효과:** 사용자가 다음 행동을 실제로 수행하는지, 가족 전체의 수고가 줄어드는지 확인한다. 화면 선호·질문 생성만으로 통과시키지 않는다.
3. **운영:** 누가 자료를 갱신하고 미해결 사례를 맡으며, 그 비용을 누가 부담할지 실증에서 확인한다. 정부·기관 구매 의사는 미검증이다.
