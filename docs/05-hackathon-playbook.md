## 4. 발표 형식과 시간 확인 사항

안내에는 **제목 1장 5초 + 본문 8장 각 15초 + 마지막 데모·정책 1장 60초**로 적혀 있다. 합계는 **185초**로, ‘3분’ 표기와 5초 차이가 있다. 자동 전환 설정·정확한 발화 시간은 운영진에게 확인해야 한다. 확인 전에는 10장 구조를 유지하고, 마지막 발화를 55초 안에도 마칠 수 있도록 준비한다. 공유 템플릿의 타이밍을 임의 변경하지 않는다. [발표 형식 원문](https://ai-impact-guide.vercel.app/)

### 표지 1장 + 본문 9장 구성

현재 방향의 [공공성·근거 중심 9장 스토리보드](templates/pitch-script.md)를 기준으로 제작한다. 외국인주민 인구 변화 → 디지털 이용 통계 → 한 업무의 실제 절차 → 국내외 정책 대응 → 상황에서 실행까지의 제품 설계 → 첫 검증 범위·AI 역할 → 사회적 가치의 측정 → 공공 협력 → 작동 증거로 이어진다. 별도 표지 1장을 더해 행사 형식의 총 10장으로 맞춘다.

개인·부부 경험은 내부 발견 자료로만 유지한다. 6인 팀원 중 누구나 발표할 수 있는 공공적 목적을 중심에 둔다. 수치·분모·출처와 해석 한계는 [발표 근거](16-public-interest-evidence.md)를 따른다. 배경 인구를 제품 수혜 인원으로 계산하지 않는다.

상황별 추천·약제비 청구·AI 활용은 목표 경험이고 현재 구현은 시술 전 서류 준비 도구다. 목표 화면과 실제 데모를 구분한다. 첫 검증 업무는 약제비 청구 한 건이며, 한 담당 창구·4주·10가구 이내는 협의 전 후속 실증 제안이다.

## 5. 메인 데모

아래 제품 시연은 합성 사례다. 사용자·배우자의 개인 경험을 발표의 주인공으로 사용하지 않는다. 실제 슬라이드 공개·제출은 아직 수행하지 않았다.

1. [로컬 화면 B](http://127.0.0.1:8973/prototype/?view=B)에서 서초구·법률혼·시술 전 조건을 확인한다.
2. 정부24 서류 목록을 직접 제출·공무원 조회·본인정보 제공 요구로 구분해 본다. 전부 발급·전부 생략이라는 뜻이 아님을 설명한다.
3. 직접 제출이 필요한 경우의 공식 준비 경로를 펼친다. 자동 발급·인증 연동은 아니다.
4. 보험 미확인, 체류 증빙 적용, 기한 상충을 담당 창구에 물을 질문으로 확인한다.
5. 일본어로 바꿔 같은 조건을 유지하고 문의 준비서를 복사·인쇄한다.

마지막 장: 0~8초 현재 구현·합성 조건 → 8~22초 서류 구분·경로 → 22~35초 일본어·미확인 질문·준비서 → 35~47초 약제비 확장 검증과 담당 창구·가족센터 요청 → 47~55초 함께 이용할 수 있는 행정이라는 공공적 목적으로 마무리한다. 정확한 조작·발화는 [스토리보드](templates/pitch-script.md)를 따른다.

현재 로컬 규칙 기반 앱은 구현됐고 AI는 미연결이다. 행정·일본어 사람 검토와 사용자 화면 테스트, 배포·영상은 남았다. 고정 자료 도구를 AI 생성으로 소개하지 않는다. 해커톤에서 AI 작동을 보여주려면 실제 연결과 기여 검증을 별도 완료해야 한다.
