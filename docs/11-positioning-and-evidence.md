# 방향 재설정·경쟁 근거

기준일: 2026-09-17 · 상태: 방향 변경, 효과 검증 전

## 1. 결정

**MARO의 제품 가설은 자신의 상황에서 관련 지원사업·행정업무를 찾고, 쉬운 단계로 실행하도록 돕는 것이다.** 외부 포스트 입력은 선택 사항이다. 현재 구현은 서초구 시술 전 준비 비교 도구다. 약제비 경험을 반영한 다음 검증 사례·실행 경계는 [13 분석](13-discovery-to-application.md)에 정리했다. 실제 난임 경험 공개는 요구하지 않는다.

- 주된 결과물: 조건 요약, 사용자가 아직 확인하지 않은 준비 항목, 근거가 상충하는 항목, 담당 창구에 가져갈 한일 질문 묶음.
- 첫 경험 응답을 반영해 ‘서류·용어의 뜻과 준비 행동 연결’을 검증 후보에 추가했다. 남편 한 명의 두 사건 경험이며 외국인 당사자의 직접 응답이나 일반화 근거는 아니다. 내부 기록은 [H01](research/session-H01.md)에 있다.
- 가족 역할 배정과 일반 Task 완료는 보조 기능으로 내린다. 이번 검증용 화면에서 제외한다.
- 자격 승인·신청 준비 완료 점수·기한 계산을 제공하지 않는다. 사용자의 ‘준비했음’과 기관·자료의 확인 상태를 구분한다.
- 지속 이용·유료 수요·기관 구매 의사는 미검증이다. 경쟁력은 기능 개수보다 실제로 줄인 누락·반복 설명·준비 부담으로 판단한다.

## 3. 차별성 가설

| ID | 검증할 가설 | 반증 신호 |
| --- | --- | --- |
| H-PREP | 공식 정보를 읽어도 자기 상황의 미확인 조건·준비 누락을 놓친다 | 기존 안내만으로 필요한 행동을 정확히 설명 |
| H-TERM | 일반 한국어 능력과 별개로 서류·행정 용어를 준비 행동에 연결하기 어렵다 | 쉬운 용어 설명만 추가해도 충분히 해결됨; 복잡한 추가 기능 필요성은 낮아짐 |
| H-PACKET | 조건별 점검과 질문 묶음이 같은 내용의 정적 안내보다 누락을 줄인다 | 동일 정보 정적 안내와 차이 없음 또는 입력 부담 증가 |
| H-HANDOFF | 질문 묶음이 상담 시 반복 설명을 줄일 수 있다 | 상담원이 필요 없다고 하거나 다시 처음부터 묻는 편이 빠름 |
| H-CHOICE | 당사자가 원하는 참여 방식과 가구 부담을 함께 개선할 수 있다 | 기존 분담에 만족하고 추가 관리만 생김 |

이 가설들은 이미 입증한 차별점이 아니다. 특히 H-HANDOFF는 상담 경험자·실무자의 관찰이 추가로 필요하다.

## 4. 경쟁력 축적의 후보

- 적용 조건과 예외를 검토한 자료 및 변경 이력.
- 실제 준비 과정에서 반복되는 누락·추가 문의 유형과 해결 기록.
- 한일 질문 표현의 이해도 검토와 담당 창구가 활용할 수 있는 형식.
- 수정 책임과 사용자에게 변경을 알리는 운영 방식.

현재는 위 자산이 충분히 축적되지 않았다. 공공 데이터를 모았거나 AI를 연결했다는 사실만으로 방어 가능한 경쟁우위를 주장하지 않는다. 범위를 넓힐 때의 검토 인력·운영비도 함께 측정한다.

## 5. 검증의 순서

1. 공개 서비스·공식 자료를 같은 사례로 조사한다. 기능 존재·응답 관찰·효과 추정을 구분한다.
2. 동일 자료를 쓰는 정적 안내와 준비 점검 화면으로 비교 도구를 만든다. 모델 효과는 여기서 주장하지 않는다.
3. 최근 행정 경험을 듣고 실제 준비 누락·반복 문의·인증 장벽을 구분한다.
4. 같은 정보를 가진 두 화면에서 누락·오해·질문 작성 과제를 수행한다.
5. [유지·수정·전환 기준](04-validation.md)에 따라 결정한다. 사용자 검증이 없으면 시장·효과 검증 완료라고 발표하지 않는다.

## 6. 경험·경쟁 관찰 후 범위 조정

H01의 후속 답변에서 출발 자료가 정부24였고 서류마다 다른 페이지로 이동해 준비하는 수고가 드러났다. 시간 손실은 아직 측정하지 않았다. 정부24는 직접 제출·공무원 조회·본인정보 제공 요구를 구분하므로, 목록을 그대로 필수 발급 목록으로 바꾸면 오히려 부담을 늘릴 수 있다.

추가 가설 H-DOC: **서류 필요성·조회 대체 가능성을 먼저 확인하고, 필요한 공식 준비 경로를 연결하면 탐색·해석 부담이 줄어든다.** 쉬운 정적 안내만으로 충분하거나 인증·권한 때문에 같은 곳에서 막히면 반증·범위 조정 신호다.

MY SEOUL+ Q2에서 문의 질문 4개 생성이 관찰됐다. 질문 생성은 차별성이 충분하지 않으며 보조 결과물로 둔다. 주된 가치 제안은 서류 준비 행동의 연결로 수정한다. 실제 면제 여부는 기관 확인 전 확정하지 않는다. [실제 관찰](12-comparative-validation.md)

## 7. 세 단계의 연결을 검증

H01의 후속 응답은 필요 서류 판단·발급 경로 탐색·로그인/인증/옵션 단계에 수고가 있었다는 것이다. 따라서 추가 가치 가설은 '내게 필요한 서류에서 실제 준비 화면의 다음 행동까지 연결'하는 것으로 구체화한다. 단순 링크·문의 질문만으로 해결된다고 보지 않는다.

후속 응답은 안내와 이용 제한 모두 있었다는 것이다. 약제비 신청을 위한 방문도 미해결이었다고 전달받았다. 구체적 원인과 개인 상태 정보가 필요하며, 현재 프로토타입이 이 문제를 해결한다는 주장은 하지 않는다.
