# 채팅 참고 구현과 추가 목업

2026-09-18. 참고 저장소: https://github.com/maakcode/seoul-mate
확인 커밋: 467ad53b5603c1c4b4635baae55dae11f55d2651

참고 구현의 공개 코드와 README를 확인했다. 해당 프로젝트는 OpenAI와 서울시 API로 자료를 검색하는 별도 서버를 갖고 있다. 이번에는 기존 60초 녹화용 범위를 유지하여 그 서버나 검색 카탈로그를 복제·실행하지 않았다. 가져온 기능 흐름은 답변 진행 상태, 중지·재시도, 근거 및 확인일의 분리 표시다. 디자인은 기존 SeoulMate 앱의 흰색·파란색·하단 탭을 유지했다.

추가한 것은 목표 언어로 풀어쓴 행정 용어 카드와 직접 선택한 자치구에 맞춘 문의 카드다. 행정 용어는 원래 한국어 명칭을 함께 남겨 실제 창구에서 사용할 수 있도록 한다. 지역별 답변은 금천·마포·강남의 예시이며 GPS 취득·주소 자동 판별·최단거리 계산이 아니다. 사용자 선택을 답변별로 고정해, 지역 설정을 나중에 바꿔도 이전 답변의 맥락이 바뀌지 않도록 한다.

금천구 전용 약제비 기준은 다른 자치구에 복제하지 않는다. 임금·퇴직금은 사업장 소재지가 중요하므로 거주 자치구를 노동관서 관할로 단정하지 않는다. 체류기간·체류자격 상담은 1345로 안내한다. 구청 링크는 관할 창구를 찾는 출발점이고 방문 예약·처리 완료·가까운 창구의 실시간 확인은 아니다.

루트 .env를 생성해 텍스트 편집기로 열었다. OPENAI_API_KEY와 SEOUL_API_KEY만 준비했으며 값은 읽거나 기록하지 않았다. 저장소 전체를 제공하던 미리보기를 정적 자산 허용 목록 방식으로 바꿔 .env, 숨김 경로, 내부 문서, 디렉터리 목록을 차단한다. 실제 키 검증과 외부 API 호출은 하지 않았다.

지역 링크: https://www.geumcheon.go.kr/ · https://www.mapo.go.kr/ · https://www.gangnam.go.kr/

검증: 일본어 용어 설명, 선택 지역 반영, 타 자치구의 금천구 기준 차단, 중지 후 늦은 응답 폐기, 재시도 시 사용자 메시지 중복 방지, 320~1440px 레이아웃, 외부 요청 없음, 비공개 경로 404를 확인했다.
