# SeoulMate 정책 제안서 — 1장 편집용 초안

**제안명:** 내 상황에서 신청까지 이어지는 생활행정 실행 지원 실증  
**제안팀:** SeoulMate · **주제:** 디지털 소외 · **기준일:** 2026-09-17

## 문제

2024년 외국인주민은 전국 약 258만 명, 서울 450,888명이다. 다양해진 주민 구성을 수용하고, 자격이 있는 주민이 필요한 서비스를 실제로 이용할 수 있는 행정 접근성을 높이고자 한다. 이 인구는 한국국적 취득자·국내 출생 자녀를 포함하며 제품 수혜 인원을 뜻하지 않는다. [행정안전부 통계와 해석](16-public-interest-evidence.md)

자신에게 관련된 지원을 판단하고 서류·인증·기관별 절차를 연결하는 과정에서 진행이 멈추거나 가족에게 업무가 집중될 수 있다. 첫 대상은 디지털 도구 사용은 가능하지만 한국 행정에 익숙하지 않은 외국인 주민이다.

한국에는 이미 맞춤형 안내·통역·사례관리가 있다. SeoulMate는 내 상황에서 필요한 업무를 찾고 실제 실행·막힘 해결까지 연결하는 추가 가치를 검증한다. 기존 서비스보다 우수하다는 결과는 아직 없다. [국내외 근거](14-australia-canada-lessons.md)

## 솔루션과 범위

상황 입력 → 관련 사업·업무와 적용 확인 → 한 번에 한 행동 → 막힘 해결·담당 지원 연결 → 접수·보완 상태 확인.

첫 실행 검증은 난임 약제비 청구 한 건으로 좁힌다. 관할별 실제 경로 확인은 남아 있다. 현재 로컬 앱은 서초구 시술 전 서류 준비 도구이며 약제비 청구·개인 잔액 조회·AI는 미구현이다. 실제 행정 결과를 임의로 판정하지 않는다.

## 서울시에 요청하는 지원

MY SEOUL+의 선정 정책 안내에서 SeoulMate 실행 화면으로 이어지는 한 업무 시범 연계를 제안한다. 운영부서·사업 담당자·지원센터가 진입 경로와 미해결 회신을 함께 검토한다. 현재 목업은 MY SEOUL+ 공개 안내 링크와 사용자 질문 복사만 제공하며 API·예약·처리 상태 연동은 아니다. [연계안](17-my-seoul-integration.md)

1. **한 사업 담당 창구:** 적용 조건·서류·인증·접수·보완·잔액 확인 경로 검토와 변경 확인 담당.
2. **이용자·지원기관 연결:** 가족센터·외국인 지원기관의 자발적 참여자 모집 협조, 미해결 사례 전달·회신 방식 협의.
3. **후속 연계 검토:** 효과 확인 후 가능한 범위에서 동의 기반 처리 상태 조회·가족 지원 권한의 연결 검토.

신규 API 구축은 초기 검증의 선행 조건이 아니다. 합성 프로토타입은 공개 자료로 시작하고, 개인 상태 조회와 대리 권한은 실제 기관 협의 없이 제공한다고 하지 않는다.

## 실증·수혜·평가

협의 후 한 사업·10가구 이내·4주를 제안한다. 자료·담당·동의 확인 → 준비·접수 관찰 → 실패 원인·가구 활동 시간·운영 비용을 검토한다. 실제 수급이 기간 내 관측되지 않으면 지급 효과는 미확인으로 남긴다.

신청자는 다음 행동 이해와 직접 수행, 가족은 대신 검색·설명하는 수고 감소, 기관은 반복 설명·보완 업무 감소가 기대된다. 현재 정량 효과는 미측정이다. 본인·가족 활동 시간을 합산해 단순한 부담 이전과 구분하고, 접수 확인·도움·오해·재방문을 기록한다. 정책 접근 개선이 지원금 집행 증가로 이어질 수 있어 정부 비용 절감을 확정하지 않는다.

공공은 업무 적용·연계 검토, SeoulMate는 화면·자료 갱신·언어 검토·오류 수정과 평가를 맡는다. 실제 사례에서 수집할 정보·접근·보관 범위를 사전에 정하고, 초기에는 합성 사례를 사용한다. 확대 전 운영 인력·비용과 책임 주체를 확인한다.
