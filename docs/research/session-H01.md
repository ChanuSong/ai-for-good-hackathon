# H01 — 한국인 배우자의 준비 경험

기록일: 2026-09-17 · 내부 검증 기록 · 외부 발표·인용 동의 미확인

## 응답의 출처

- 응답자: 이 대화의 사용자, 한국인 남편. 본인이 맡았던 업무의 경험을 직접 설명함.
- 가구 수 1, 응답자 수 1, 언급된 사건 2. 아내 본인의 응답이나 독립 가구 두 건이 아님.
- 사용자는 배우자 대신 자신과 이야기하면 된다고 명시함. 배우자에게 별도 참여를 전제하지 않는다.
- 실제 진단, 계좌, 식별번호, 주소·금액은 수집하지 않는다. 공개 데모의 합성 프로필과 이 기록을 결합하지 않는다.

## 전달받은 내용

사용자는 난임 지원 신청 때 모든 서류 준비를 본인이 맡았다고 설명했다. 이유로 아내가 절차에 익숙하지 않고, TOPIK 6급이어도 행정 용어가 낯설다는 점을 들었다. 전세자금대출 때도 행정절차를 본인이 맡았다고 설명했다.

## 확인된 것 / 해석 / 미확인

| 구분 | 기록 |
| --- | --- |
| 직접 경험 | 남편이 두 사건의 서류·행정 준비를 맡았다는 자기보고. 난임 지원에서는 여러 서류를 직접 발급해 제출했다고 후속 확인 |
| 배우자에 대한 남편의 설명 | 높은 한국어 능력에도 생소한 행정 용어·경험 부족이 있다고 봄 |
| 잠정 해석 | 일상·시험 한국어와 서류를 준비하는 지식은 별개일 수 있음. 용어 이해와 발급 절차의 연결이 가치 후보 |
| 아직 미확인 | 발급·제출한 서류의 구체적 종류와 개수, 직접 제출 이유, 일부 서류의 동의·조회 생략 여부, 로그인·인증·옵션 단계에서의 구체적 원인, 들인 시간, 누락·재방문, 분담 만족도 |
| 주장하지 않을 것 | 모든 혼합국적 가구의 문제, 아내 본인의 불만·참여 의사, SeoulMate가 부담을 줄인다는 효과 |

## 제품에 반영할 가설

기존의 ‘누락 점검·문의 질문’에 앞서 **서류의 뜻 → 이 사례에서 확인할 이유 → 준비 경로 → 당사자가 확인할 조건**을 이해시키는 것이 필요한지 검증한다. 용어만 쉽게 풀어도 충분하다면 복잡한 로드맵 기능을 추가하지 않는다.

## 후속 응답과 남은 확인

후속 답변을 받았다. 사용자는 [정부24 안내](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=14600000394)에서 서류를 알게 됐고, 목록이 많았다고 설명했다. 본인은 서류마다 다른 페이지에서 발급하면 되지만 아내에게는 어렵고 시간이 더 들 것으로 예상했다. 이는 배우자의 실제 수행 측정 결과가 아니다.

제시된 목록: 시술 지원신청서, 주민등록등(초)본, 직장·지역 건강·장기요양 보험료납부확인서, 건강보험 자격확인서, 수급 증명서, 차상위 확인서, 외국인등록사실증명, 국내거소신고사실증명, 출입국기록증명.

현재 공식 페이지는 신청서·진단서와 별도로 나머지 9개를 정보제공 동의 후 공무원 조회 가능 항목으로 안내한다. 이는 과거 경험의 반박이 아니다. 당시 실제로 발급한 것, 기관에서 요구한 것, 정보제공 동의로 생략한 것을 아직 구분하지 못했다.

후속 응답: “여러 서류를 직접 발급해 제출했다.” 실제 발급·제출 행동을 본인의 회상으로 확인했다. 앞서 제시한 목록 전체를 발급했다는 뜻이나 정보제공 동의를 전혀 하지 않았다는 뜻으로 확대하지 않는다. 구체적 서류·개수·직접 제출 이유는 아직 모른다. 현재 자료를 보며 한 구분을 과거 당시의 인식으로 소급하지 않는다.

병목 질문에 대한 후속 응답: “1,2,3.” 제시한 선택지 중 ① 필요한 서류 판단, ② 발급 사이트·메뉴 찾기, ③ 로그인·인증·발급 옵션 선택을 골랐다. 세 단계 모두 수고가 있었다는 자기보고로 기록하며, 단계 사이의 순위·시간·오류 횟수는 아직 모른다. ③은 묶음 선택지이므로 로그인·인증·옵션 각각에 문제가 있었다거나 실제 인증 불가였다고 확정하지 않는다. ④ 저장·출력·취합은 선택되지 않았지만 부담이 전혀 없었다고 해석하지 않는다.

검증 초점: 생략 가능한 서류를 잘못 준비했다는 가설을 앞세우지 않는다. 필요한 서류 판단 → 정확한 발급 경로 → 해당 화면의 선택·인증 안내를 연결하는 가치를 검증한다. 후속 응답에서 안내의 어려움과 실제 이용 제한 모두 있었다고 설명했다. 어떤 제한인지는 미확인이다. 구체적 원인 없이 우회나 해결 가능성을 가정하지 않는다.

## 후속 사례 — 발견에서 실행으로 넘어가는 과정

사용자는 안내의 어려움과 실제 이용 제한이 모두 있었다고 답했다. 약제비 지원 신청 때 아내가 온라인 신청 방법을 몰라 직접 보건소를 방문했지만 해결되지 않았다고 전했다. 현재 지원금이 얼마나 남았는지와 확인 방법도 모른다고 설명했다. 실제 관할, 방문 때의 답변, 미해결 원인, 잔액이 회차별 금액인지 남은 횟수인지는 확인하지 않았다.

사용자가 설명한 통상 흐름은 ① 아내가 인스타그램·스레드·블로그에서 외국인 난임 가구 사례 탐색 → ② 지원받은 사례를 남편에게 전달 → ③ 남편이 해당 지원의 행정절차를 알아보고 진행하는 것이다. 이는 아내의 정보 발견·방문 행동에 대한 남편의 설명이다. 아내가 행정에 참여하지 않거나 의지가 없다는 해석을 배제한다.

초기 두 사건(난임 지원·전세대출) 중 난임의 약제비 청구 단계가 구체화됐다. 응답자·가구 수는 여전히 각각 1이며 독립 사례 수 증가로 세지 않는다. 지원금 미수령이나 금전 손실이 확정됐다는 의미도 아니다.

제품 가설은 서류 안내에서 발견한 지원의 실제 신청·막힘 해결·상태 확인을 돕는 방향으로 확장됐다. 현재 시술 전 데모가 약제비 청구를 처리한다는 뜻은 아니다. [분석과 경계](../13-discovery-to-application.md)

## 보관·사용

내부 제품 검증 목적으로만 기록한다. 발표에 개인 경험을 쓰려면 인용·공개 범위를 별도로 확인한다. 삭제 기본일은 행사 후 7일인 2026-09-25이며 사용자 요청 시 먼저 삭제한다. 익명화되지 않은 가구 특성을 공개 자료에 복제하지 않는다.

## 사용자 정정 — 상황 중심 흐름과 부모님 경험

사용자는 제품이 외부 포스트에서 시작할 필요 없이, 내 상태를 입력하거나 정보를 가져오면 관련 지원사업·행정업무가 나오고 쉽게 처리하게 하면 된다고 명시했다. SNS 경로는 현재 행동의 사례이며 제품 요구로 고정하면 안 된다.

또한 본인이 부모님의 행정업무를 대신 처리한다고 설명했다. 아내는 쉽고 정확한 방법을 제시하면 직접 할 수 있을 것 같고 부모님은 어려울 것 같다는 평가를 덧붙였다. 부모님의 구체적 업무·장애 요인·사용 언어·디지털 수행 수준은 묻거나 확인하지 않았다. 아내와 부모님의 수행 가능성은 응답자의 예상이며 직접 관찰 결과가 아니다.

응답자 수는 여전히 1명이다. 초기의 ‘1가구·2사건’은 난임·전세대출 조사 범위였고, 이제 부모님 지원 경험이 추가 언급됐다. 부모님 가구 수와 독립 응답자를 새로 확보했다고 세지 않는다. 연령·국적만으로 능력을 일반화하지 않는다.
